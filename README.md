# Iron's Spells x Create Compat
**Minecraft 1.21.1 | NeoForge 21.1.233+ | Create 6.0+**

Adds Create **Crushing Wheel** recipes for every ring, amulet, and necklace from Iron's Spells 'n Spellbooks. Recycle unwanted jewelry into its component gems and nuggets.

## Building

Requires **Java 21** and an internet connection (downloads NeoForge + dependencies automatically).

```
gradlew build
```

The finished jar appears in `build/libs/irons_create_compat-1.0.0.jar`.  
Drop that into your `mods/` folder alongside Create and Iron's Spells.
